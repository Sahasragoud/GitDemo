## Now create the Jenkins credential

Go back to:

**Jenkins → Manage Jenkins → Credentials → System → Global credentials → Add Credentials**

Choose **Secret text**.

Use:

**Secret:**

```text
jdbc:postgresql://192.168.117.1:5432/<YOUR_DATABASE_NAME>
```

For example, if your DB is `ridehub`:

```text
jdbc:postgresql://192.168.117.1:5432/ridehub
```

**ID:**

```text
ridehub-db-url
```

**Description:**

```text
RideHub PostgreSQL JDBC URL
```

Create it.

Then create the second credential:

**Username with password**

```text
Username: postgres
Password: <your PostgreSQL password>
ID: ridehub-db
```

### Then our Jenkinsfile test stage will look like this

```groovy
stage('Test') {
    steps {
        dir('RIDEHUB USER AUTHENTICATION') {
            withCredentials([
                string(
                    credentialsId: 'ridehub-db-url',
                    variable: 'DB_URL'
                ),
                usernamePassword(
                    credentialsId: 'ridehub-db',
                    usernameVariable: 'DB_USERNAME',
                    passwordVariable: 'DB_PASSWORD'
                )
            ]) {
                sh 'mvn clean test'
            }
        }
    }
}
```

That gives your Spring Boot application:

```text
DB_URL
DB_USERNAME
DB_PASSWORD
```

during the Maven test execution.
