Got it 👍 — **PostgreSQL is running on a Windows host**, and Jenkins is connecting to it from `192.168.117.9`.

Your setup is roughly:

```text
Jenkins
192.168.117.9
      │
      │ PostgreSQL :5432
      ▼
Windows PostgreSQL host
192.168.117.1
      │
      ▼
ridehub_db
```

Let's fix it step by step.

### 1. Find `pg_hba.conf`

On your **Windows PostgreSQL host**, open **pgAdmin**.

Go to:

**Servers → PostgreSQL → Databases → ridehub_db**

Then open **Tools → Query Tool** and run:

```sql
SHOW hba_file;
```

It will return something similar to:

```text
C:/Program Files/PostgreSQL/17/data/pg_hba.conf
```

Copy that path.

---

### 2. Open `pg_hba.conf` as Administrator

Navigate to that file in Windows Explorer.

Right-click **Notepad → Run as administrator**, then open:

```text
pg_hba.conf
```

At the bottom, add:

```text
host    ridehub_db    postgres    192.168.117.9/32    scram-sha-256
```

So you might have something like:

```text
# IPv4 local connections:
host    all             all             127.0.0.1/32            scram-sha-256

# Jenkins server
host    ridehub_db      postgres        192.168.117.9/32        scram-sha-256
```

**Save the file.**

---

### 3. Check `postgresql.conf`

In pgAdmin's Query Tool, run:

```sql
SHOW config_file;
```

Open that file and find:

```text
listen_addresses
```

If you have:

```text
listen_addresses = 'localhost'
```

change it to:

```text
listen_addresses = '*'
```

Or, more securely for your setup:

```text
listen_addresses = '192.168.117.1'
```

Also make sure:

```text
port = 5432
```

Save the file.

---

### 4. Restart PostgreSQL on Windows

Press:

**Win + R → `services.msc` → Enter**

Find your PostgreSQL service, something like:

```text
postgresql-x64-17
```

Right-click → **Restart**.

---

### 5. Check Windows Firewall

This is the next thing I'd check if Jenkins still can't connect.

On the PostgreSQL Windows machine, open **Windows Defender Firewall with Advanced Security**.

Create an **Inbound Rule**:

```text
Rule type: Port
Protocol: TCP
Specific local port: 5432
Action: Allow
```

Ideally restrict the rule to the Jenkins machine:

```text
Remote IP: 192.168.117.9
```

Don't open PostgreSQL's 5432 port to the entire internet.

---

### 6. Test from Jenkins

On the Jenkins machine, try:

```bash
psql -h 192.168.117.1 -p 5432 -U postgres -d ridehub_db
```

If `psql` isn't installed, on Windows you can at least test the port with PowerShell:

```powershell
Test-NetConnection 192.168.117.1 -Port 5432
```

You want:

```text
TcpTestSucceeded : True
```

Then test the actual PostgreSQL login if `psql` is available.

---

### 7. Then run Jenkins

Once this works:

```text
192.168.117.9
       ↓
192.168.117.1:5432
       ↓
ridehub_db
       ↓
postgres authentication ✅
```

your original:

```text
FATAL: no pg_hba.conf entry for host "192.168.117.9"
```

should be gone.

And the Hibernate error:

```text
Unable to determine Dialect without JDBC metadata
```

should disappear as well, because that was a **secondary error caused by PostgreSQL rejecting the connection**.
